Overview & Key Features

Medians Chat is an innovative, high-performance Laravel-backed interactive portfolio CMS. It seamlessly combines server-side dynamic Blade view rendering with a sleek Inertia.js + React 19 single-page application (SPA) admin dashboard.

Interactive Chat Engine

Driven by smart trigger matching logic and OpenAI completions to guide visitors interactively through portfolio flows.

Inertia + React 19 Admin

Ultra-fast SPA admin interface powered by React 19, TypeScript, TanStack Query, and Lucide React icons.

Dynamic CMS Sections

Fully manage intro, about, skills, projects, clients, contact, CV, education, and hobbies via database JSON casts.

Web Speech API

Built-in voice input speech recognition and browser-native Text-to-Speech (TTS) audio synthesis controller.

Media Library

Full upload manager with MIME validation, drag & drop uploads, security file checks, and instant previewing.

Multi-Theme Skins

Includes customizable CSS themes (Dark, Light, Custom accents) with a real-time skin selector widget.

System Requirements

Ensure your hosting server meets the following software requirements before proceeding with installation:

Server & Backend

  • PHP: ^8.2.4 (PHP 8.2 or 8.4 recommended)
  • Database: MySQL 8.0+ or MariaDB 10.4+
  • Web Server: Apache (with mod_rewrite) or Nginx
  • Composer: 2.x
  • Node.js: 18.x or 20.x + npm 9+

Required PHP Extensions

  • OpenSSL, PDO & PDO_MySQL
  • Mbstring, Tokenizer, XML
  • Ctype, JSON, BCMath
  • Fileinfo, Zip, cURL
Note for Shared Hosting (cPanel): Ensure PHP 8.2+ is enabled in cPanel → Select PHP Version and that fileinfo and zip extensions are active.

Step-by-Step Installation Guide

Method A: Local Development (XAMPP / Laragon / Artisan)

  1. 1
    Extract Files & Place Project
    Extract the downloaded package zip and copy the contents into your web root directory (e.g. c:\xampp\htdocs\medians_chat or Laragon www/medians_chat).
  2. 2
    Configure Environment (.env)
    Copy .env.example to .env and set your database connection details:
    .env 
    APP_NAME="Medians Chat"
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=medians_chat
DB_USERNAME=root
DB_PASSWORD=
  3. 3
    Install PHP & Node Dependencies
    Open terminal in the project directory and run:
    Terminal 
    composer install
npm install
  4. 4
    Generate App Key & Seed Database
    Run the database migrations and default seeders to generate demo content and the default admin user:
    Terminal 
    php artisan key:generate
php artisan migrate --seed
php artisan storage:link

Method B: Production Deployment (cPanel / VPS)

Document Root Setup: Your domain or subdomain must point directly to the /public directory of the script for security and routing to function correctly.
  • 1. Upload all script files to your server directory (e.g. public_html/medians_chat).
  • 2. Set your web server domain document root to public_html/medians_chat/public.
  • 3. Create a MySQL database and user via cPanel MySQL Wizard.
  • 4. Update your .env file with production database details, APP_ENV=production, APP_DEBUG=false, and your live APP_URL=https://yourdomain.com.
  • 5. Set write permissions (775 or 777) on storage and bootstrap/cache directories.

CMS Content Sections Architecture

The application employs a dynamic, JSON-driven CMS architecture. All section content is stored in the content_sections database table (using section_key as the primary key and a JSON cast data column), managed by App\Services\ContentService, and delivered via REST endpoints or server-side Blade view binding in HomeController.

Database Storage & Model

Driven by the ContentSection Eloquent model (app/Models/ContentSection.php). The data attribute is automatically cast to a native PHP array/JSON object.

Service & Controller Layer

ContentService handles all data retrieval and updates, consumed by ContentController for admin REST API calls and HomeController for initial view data.

Master Blade Component Engine

All chat flows and content sections are rendered dynamically using a single master layout engine: resources/views/sections/index.blade.php.

React SPA Admin Editors

Built with Inertia.js + React 19 in resources/js/src/pages/admin/content/sections/ for intuitive, real-time section content editing.

System & AI Settings Architecture

Medians Chat features a centralized configuration engine that stores system-wide settings, AI integration keys, security configurations, and mail parameters in the settings database table. Config entries are retrieved with high-performance Laravel caching, managed through the SettingService, and edited interactively in the Inertia + React 19 SPA dashboard via GeneralSettingPage.

Database Model (Setting.php)

Driven by App\Models\Setting. Columns include group, key, label, value, type, options, description, is_public, is_encrypted, and sort_order. Values are dynamically cast (boolean, integer, json, string) and encrypted using Laravel Crypt when marked encrypted.

Service Layer (SettingService.php)

Encapsulates setting access, grouping (getGrouped(), getGroup()), type validation (validateValue()), and bulk updates (bulkUpdate()). Flushes settings cache automatically upon mutation.

React SPA Editor (GeneralSettingPage.tsx)

Tabbed settings management SPA built with React 19 and TypeScript. Features specialized input controls (SettingField) for toggles, select menus, textareas, media pickers, and number inputs with instant save feedback.

Forever Caching Strategy

Utilizes Cache::rememberForever for key lookups (setting:{key} and settings:all). Eliminates repetitive database queries on high-traffic frontend user prompts and system calls.

Developer Code Examples

1. Accessing Settings in PHP Backend:

Backend Controller / Service 
use App\Models\Setting;

// Retrieve setting with fallback
$appName = Setting::getValue('app_name', 'Medians Chat');

// Programmatically update a setting and clear cache
Setting::setValue('maintenance_mode', false);

PUT /api/v1/settings 
{
    "app_name": "Medians Interactive Portfolio",
    "site_title": "Medians Chat - AI Portfolio",

Troubleshooting & FAQ

Q: I get a "500 Internal Server Error" after uploading to cPanel.

Fix: Ensure your .env file exists, run php artisan key:generate, and make sure storage and bootstrap/cache folders have 775 permissions.

Q: Admin routes return a 404 error on page refresh.

Fix: Verify Apache mod_rewrite is enabled and public/.htaccess is present. On Nginx, ensure your config includes try_files $uri $uri/ /index.php?$query_string;.

Q: Uploaded project portfolio images are not showing.

Fix: Run php artisan storage:link in your terminal to create the public storage shortcut link.
