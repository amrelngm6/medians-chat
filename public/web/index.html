KEY FEATURES

A CMS That Talks Back

Interactive Chat & Flow Engine

Visitors explore the portfolio through conversational prompt flows, keyword trigger matching, and quick-action UI chips — a browsing experience that feels like chatting with an assistant, not scrolling a page.

Inertia.js + React 19 Admin Portal

An ultra-fast single-page admin application powered by React 19, TypeScript, and TanStack Query. Manage every CMS content section, media asset, and setting without a full page reload.

Media Library Manager

A centralized file uploader with drag-and-drop uploads, MIME-type security validation, and one-click URL copying so you can drop assets straight into any CMS field.
